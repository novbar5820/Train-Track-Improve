# FitJourney

אפליקציית PWA אישית למעקב אימונים, תזונה ומשקל. נבנתה כ-MVP להתקנה ושימוש ישיר על מסך הבית באייפון (Add to Home Screen), ללא צורך ב-App Store.

כל הנתונים נשמרים **מקומית במכשיר** (IndexedDB) - אין שרת ואין שיתוף נתונים עם צד שלישי.

## פיצ'רים

- בניית תוכניות אימונים (ימים + תרגילים + סטים/חזרות/מנוחה)
- ספריית תרגילים (~75 תרגילים) עם אייקון ויזואלי פשוט לפי קבוצת שריר
- מסך אימון פעיל: טיימר, עריכת משקל/חזרות/סטים, טיימר מנוחה בין סטים, וזיהוי שיא אישי (PR)
- שמירת הנתונים האחרונים לכל תרגיל, עם מילוי אוטומטי באימון הבא
- סיכום שבועי: שני התרגילים עם השיפור היחסי הגדול ביותר, ואחד עם השיפור הנמוך ביותר
- מעקב קלוריות ומאקרו (חלבון/שומן/פחמימה) עם מאגר מזון (~150 פריטים) ויחידות מידה (גרם/כוס/כף/יחידה...)
- מחשבון יעד קלוריות ומאקרו (TDEE) לפי גיל/מין/גובה/משקל/פעילות/מטרה
- יומן משקל עם ממוצע שבועי, השוואה לשבוע קודם והודעות חיזוק
- הגדרת יום תחילת השבוע

## איך מתקינים על האייפון

1. ודא/י שהאפליקציה פרוסה (deployed) ל-GitHub Pages - ראה/י "פריסה" למטה.
2. פתח/י את הקישור בדפדפן **Safari** באייפון (חובה Safari, לא כרום).
3. הקש/י על כפתור השיתוף (הריבוע עם החץ) ואז "הוסף למסך הבית" (Add to Home Screen).
4. האפליקציה תופיע כאייקון רגיל במסך הבית, ותיפתח במסך מלא כמו אפליקציה טבעית.

## פריסה (Deployment) ל-GitHub Pages

בריפו מוגדר workflow אוטומטי (`.github/workflows/deploy.yml`) שבונה ומפרסם את האפליקציה בכל push לענף `main`.

**צעד חד-פעמי נדרש:** ב-GitHub, בהגדרות הריפו → Settings → Pages → תחת "Build and deployment" יש לבחור Source = **GitHub Actions**.

לאחר מיזוג לענף `main`, האפליקציה תהיה זמינה בכתובת:
`https://<שם-המשתמש>.github.io/train-track-improve/`

## פיתוח מקומי

```bash
npm install
npm run dev       # שרת פיתוח
npm run build     # בנייה לפרודקשן ל-dist/
```

## טכנולוגיה

React + TypeScript + Vite, ניתוב עם `react-router-dom` (HashRouter, כדי לתמוך באחסון סטטי כמו GitHub Pages), אחסון נתונים עם Dexie (IndexedDB), ו-Service Worker בסיסי לתמיכה אופליין.
